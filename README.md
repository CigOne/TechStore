# TechStore — Интернет-магазин

Полнофункциональный интернет-магазин с админ-панелью, корзиной, авторизацией и AI-ассистентом для сравнения товаров.

## Технологии

- **Frontend:** Vue 3 + Vue Router + Pinia + Tailwind CSS
- **Backend:** Express.js + SQLite
- **AI:** Ollama (локальная нейросеть, бесплатно)
- **Стили:** Тёмно-зелёная тема

## Функции

- Каталог товаров с фильтрами (категории, цена, поиск)
- Страница товара с описанием
- Регистрация и вход пользователей
- Корзина с добавлением/удалением товаров
- Админ-панель с CRUD товаров и категорий
- Загрузка изображений с компьютера (не только URL)
- AI-сравнение товаров из одной категории
- Адаптивный дизайн (работает на телефоне)

## Требования

- Node.js 18+
- Windows / Linux / macOS

## Установка

### 1. Установить зависимости

```bash
# В корневой папке проекта
cd ecommerce
npm install

# Установить зависимости сервера
cd server
npm install

# Установить зависимости клиента
cd ../client
npm install
```

### 2. Настройка окружения

Файл `.env` уже создан и настроен. При необходимости можно изменить:

```env
PORT=3000                    # Порт сервера
SESSION_SECRET=super_secret_key_change_me  # Секрет для сессий
ADMIN_USERNAME=admin         # Логин админа
ADMIN_PASSWORD=admin123      # Пароль админа
```

### 3. Запуск

**Способ 1 — Один порт (рекомендуется для просмотра с телефона):**

```bash
cd ecommerce/server
node index.js
```

Сайт откроется по адресам:
- `http://localhost:3000/` — на этом компьютере
- `http://192.168.x.xxx:3000/` — с телефона в той же WiFi

**Способ 2 — Два окна (для разработки):**

```bash
# Окно 1 — Сервер
cd ecommerce/server
node index.js

# Окно 2 — Клиент (дев-режим)
cd ecommerce/client
npm run dev
```

Клиент: `http://localhost:5173/`
Сервер: `http://localhost:3000/`

## AI-ассистент (сравнение товаров)

Для работы AI-сравнения установите Ollama:

1. Скачайте с https://ollama.com
2. Установите
3. В PowerShell выполните:
```powershell
ollama pull qwen2.5:7b
ollama run qwen2.5:7b
```

Без Ollama сравнение работает в базовом режиме (цены + описания).

## Структура проекта

```
ecommerce/
├── .env                 # Настройки окружения
├── .env.example         # Шаблон настроек
├── server/              # Backend (Express + SQLite)

│   ├── db.js            # База данных SQLite
│   ├── seed.js          # Демо-данные (35 товаров)
│   ├── uploads/         # Загруженные картинки
│   └── public/          # Статические файлы фронтенда
├── client/              # Frontend (Vue 3)
│   ├── src/
│   │   ├── views/       # Страницы (Home, Shop, Product...)
│   │   ├── components/  # Компоненты (ProductCard, AppNavbar...)
│   │   ├── stores/      # Хранилища Pinia (auth, products, cart, ai)

│   └── dist/            # Собранный фронтенд
└── README.md            # Этот файл
```

## База данных

SQLite файл `server/database.sqlite` создаётся автоматически при первом запуске. Включает таблицы:
- `users` — пользователи (админ + обычные)
- `products` — товары (35 демо)
- `categories` — категории (8 штук)
- `cart` — корзины пользователей

## Команды

```bash
# Сборка клиента для продакшена
cd client

# Заполнить базу демо-данными
cd server

```
